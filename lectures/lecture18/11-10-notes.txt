PROGRAM COUNTER (PC) -- special register that keeps track
                         of the next instruction to execute...

                        the $PC is incremented by 4 (one 32-bit word)
                         immediately when we start an instruction

MIPS PIPELINE -- 5 stages...

Instruction Fetch (IF)
-- retrieve the current instruction at $PC
-- then $PC <= $PC + 4

Instruction Decode (ID)
-- decode the instruction opcode/funct
-- copy required operand values from registers...(into ALU)
                                                       ^^^
                                             Arithmetic & Logic Unit
Execute (EX)
-- execute the instruction
---- so either ALU operation occurs (e.g., and, andi, or, ori, etc.)
---- or calculate memory address for load/store operation (e.g., lw, sw, etc.)

Memory Access (MEM)
-- read from or write to memory for lw, sw, etc.

Write Back (WB)
-- store the final result back to a destination register

Temporary "pipeline registers" between each of these stages...
...these hidden registers hold control signals, data that is flowing
    from one stage to the next, etc.
