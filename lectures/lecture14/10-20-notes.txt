MIPS:
-- each MIPS instruction is encoded as a 32-bit word (4 bytes)
-- a word is 4 bytes (32 bits)
-- a halfword is 2 bytes (16 bits)
-- a byte is 8 bits
-- one character == one byte
-- one integer == four bytes
-- one float == four bytes
-- one double == eight bytes (double word)

======================================================================

MIPS general registers:

 register | name(s) | primary use
----------+---------+------------------------------------------
        0 |      $0 | always contains the value 0 (e.g., ori)
        1 |     $at | assembler temporary (do not use)
      2-3 | $v0-$v1 | values for syscall or return values
      4-7 | $a0-$a3 | arguments (not preserved)
     8-15 | $t0-$t7 | temporary registers (not preserved)
    16-23 | $s0-$s7 | saved registers (preserved)
    24-25 | $t8-$t9 | temporary registers (not preserved)
    26-27 | $k0-$k1 | used for interrupts/traps...
       28 |     $gp | global pointer
       29 |     $sp | stack pointer (top location on the stack)
       30 | $s8/$fp | saved register or frame pointer
       31 |     $ra | return address (e.g., jr $ra)
----------+---------+------------------------------------------

-- Note that "not preserved" means that these register values
    may change when a function is called; conversely, "preserved"
     means that these register values must be saved when a function
      is called and then restored when we return from that function

syscall in MIPS:
-- simple mechanism for I/O and memory management
-- register $v0 determines which system call
-- inputs will be in $a0, $a1, and $f12
-- outputs (if any) are in $v0

DISPLAYING DATA:
 syscall      | $v0 | argument
--------------+-----+----------------------------------------
 print_int    |   1 | $a0 (int)  -- %d
 print_float  |   2 | $f12 (float)  -- %f
 print_double |   3 | $f12 (double)  -- %lf
 print_string |   4 | $a0 (address of string ending in '\0')  -- %s
--------------+-----+----------------------------------------

 Note that print_string keeps displaying characters until
  the '\0' character is found; use the .asciiz directive
   to declare and initialize strings; .asciiz will add '\0'

  e.g.,
   .data
   string1:   .asciiz "Hello world"  # 12-byte array (ends in '\0')
   string2:   .asciiz "ABC\n"
   newline:   .asciiz "\n"

   .text
   main:      li $v0,4        # set up to print the string pointed to by $a0
              la $a0,string1  # load the address of string1 (location of first byte) into $a0
              syscall         # print_string


READING DATA:
 syscall      | $v0 | result
--------------+-----+---------------------------------------
 read_int     |   5 | $v0 (int)
 read_float   |   6 | $v0 (float)
 read_double  |   7 | $v0 (double)
--------------+-----+---------------------------------------

 syscall      | $v0 | arguments
--------------+-----+---------------------------------------
 read_string  |   8 | $a0 (address of buffer); $a1 (length)
--------------+-----+---------------------------------------

 Note that read_string is essentially fgets(), so a '\0'
  character will be automatically added at the end


MANAGING MEMORY:
 syscall       | $v0 | argument   | result
---------------+-----+------------+-------------------------
 sbrk (malloc) |   9 | $a0 (size) | $v0 (address of memory)
---------------+-----+------------+-------------------------
