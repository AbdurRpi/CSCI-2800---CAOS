 Logical Bitwise Operators...
         ^^^^^^^

 As a "bitwise" operator, we apply AND or OR to each pair of bits
  in $t1 and $t2...

    or $t0,$t1,$t2

              OR
            +-----                       $t1 $t2 | $t0
    $t1 -----\    \                     ---------------
              |    \                       0   0 |   0
              |     >----- $t0             0   1 |   1
              |    /                       1   0 |   1
    $t2 -----/    /                        1   1 |   1
            +-----


    and $t0,$t1,$t2

              AND
            +----                       $t1 $t2 | $t0
    $t1 ----|    \                     ---------------
            |     |                       0   0 |   0
            |     |----- $t0              0   1 |   0
            |     |                       1   0 |   0
    $t2 ----|    /                        1   1 |   1
            +----

            | \                      -----------

            | /                         1 |   0
            |/

Shift-Left and Shift-Right instructions...

  sll -- shift-left logical

             binary: 00001010  (10)     each sll operation doubles the value
          after sll: 00010100  (20)
                            ^
    after sll again: 00101000  (40)
                            ^

          sll $a0,$a0,1   # shift $a0 left one bit position
                          #  (the leftmost bit is discarded)
                          #  (the new rightmost bit is 0)

          sll $a1,$a1,3   # shift $a1 left three bit positions
                          #  (the three leftmost bits are discarded)
                          #  (the new rightmost bits are 000)
                          # $a1 = $a1 * 2^3 (multiplying by a power of 2)

          e.g., in C, we might have:  x = x * 8;  ==> use sll
          e.g., in C, we might have:  x = x * 9;  ==> use sll then add x
                                      x = x * 8 + x;

  srl -- shift-right logical

             binary: 00001010 (10)
          after srl: 00000101 (5)
                     ^
    after srl again: 00000010 (2)  integer division!
                     ^

          srl $a0,$a0,1   # shift $a0 right one bit position
                          #  (the rightmost bit is discarded)
                          #  (the new leftmost bit is 0)

          srl $a1,$a1,3   # shift $a0 right three bit positions
                          #  (the three rightmost bits are discarded)
                          #  (the new leftmost bits are 000)
                          # $a1 = $a1 / 2^3 (dividing by a power of 2)
